## Getting Started

## Real-Time Shark Tracking

### Overview
Track individual tagged sharks in real-time with advanced visualization features.

### Key Features
- **Live Shark Positions**: Current locations with last-ping timestamps
- **Individual Movement Tracks**: Color-coded paths for each shark
- **Toggle Controls**: Show/hide specific shark tracks
- **Detailed Profiles**: Species information, size, tagging details
- **Status Indicators**: Active, inactive, and signal strength

### How to Use Shark Tracking

#### 1. **Viewing Active Sharks**
- Navigate to the **Map** page
- Active sharks appear as red markers (🦈)
- Inactive sharks appear as gray markers
- Click any shark marker to see detailed information

#### 2. **Controlling Individual Tracks**
- Use the **"Shark Tracks"** panel (top-right on map)
- Each shark has a colored circle indicator
- Click the circle to toggle track visibility
- Track colors correspond to movement paths on the map

#### 3. **Understanding Track Information**
- **Track Points**: Number of recorded positions
- **Color Coding**: Each shark has a unique color
- **Movement Lines**: Connect chronological positions
- **Density Circles**: Show areas of frequent activity

#### 4. **Shark Profile Details**
- **Species**: Scientific and common names
- **Physical Stats**: Length, weight, sex
- **Tagging Info**: Date, location, organization
- **Current Status**: Last ping time and location
- **Water Conditions**: Temperature, depth readings

### Track Visualization Options
- **Standard View**: Movement lines with position markers
- **Heat Map Mode**: Density visualization of activity areas
- **Time-Based Filtering**: Show tracks for specific date ranges

## Marine Heatwave Alerts

### What Are Marine Heatwaves?
Marine heatwaves are periods of unusually warm ocean temperatures that can:
- Cause coral bleaching events
- Disrupt marine food chains
- Affect fish migration patterns
- Impact coastal ecosystems

### Alert System Features
- **Real-time Monitoring**: Global ocean temperature analysis
- **Severity Classification**: Moderate, Strong, Severe, Extreme levels
- **Ecological Impact Assessment**: Species and habitat risk analysis
- **Email Notifications**: Customizable alert subscriptions
- **Historical Context**: Comparison with past events

### Understanding Alert Levels

#### **Moderate** (Yellow - 🟡)
- **Temperature**: 1-2°C above normal
- **Duration**: Typically 5-20 days
- **Impact**: Minor ecosystem stress
- **Action**: Enhanced monitoring recommended

#### **Strong** (Orange - 🟠)
- **Temperature**: 2-3°C above normal
- **Duration**: 20-40 days
- **Impact**: Noticeable species behavior changes
- **Action**: Increased surveillance needed

#### **Severe** (Red - 🔴)
- **Temperature**: 3-4°C above normal
- **Duration**: 40+ days
- **Impact**: Coral bleaching likely, fish mortality possible
- **Action**: Emergency monitoring protocols

#### **Extreme** (Dark Red - 🔴)
- **Temperature**: >4°C above normal
- **Duration**: Extended periods
- **Impact**: Mass mortality events possible
- **Action**: Crisis response activation

### Using Heatwave Alerts

#### 1. **Viewing Active Alerts**
- Navigate to **Alerts** page
- View global heatwave status dashboard
- See active alerts by region and severity

#### 2. **Subscribing to Notifications**
- Enter email address in subscription form
- Select regions of interest
- Choose severity threshold (Moderate to Extreme)
- Set notification frequency (Immediate, Daily, Weekly)

#### 3. **Understanding Alert Details**
- **Region**: Geographic area affected
- **Intensity**: Temperature anomaly in °C
- **Duration**: Days since onset
- **Affected Area**: Square kilometers impacted
- **Ecological Risk**: Species and habitat assessments

#### 4. **Coral Bleaching Risk**
Special attention to coral reef systems:
- **Risk Percentage**: Likelihood of bleaching events
- **Affected Species**: Vulnerable marine life
- **Recovery Timeline**: Expected duration for ecosystem recovery

## Troubleshooting

### Common Issues

#### **Maps Not Loading**
- **Check Internet Connection**: Ensure stable connectivity
- **Browser Compatibility**: Use modern browsers (Chrome, Firefox, Safari, Edge)
- **JavaScript Enabled**: Required for interactive features
- **Clear Browser Cache**: Refresh stored data

#### **Timeline Controls Not Responding**
- **Wait for Data Loading**: Large datasets may take time to load
- **Check Network Speed**: Slower connections need more time
- **Reduce Time Range**: Try smaller date ranges first
- **Refresh Page**: Reload if controls become unresponsive

#### **Shark Tracks Not Visible**
- **Toggle Visibility**: Check track control panel settings
- **Zoom Level**: Zoom out to see full track paths
- **Date Range**: Ensure timeline includes tracking periods
- **Data Availability**: Some sharks have limited tracking data

#### **Alert Notifications Not Received**
- **Email Verification**: Check spam/junk folders
- **Subscription Status**: Verify active subscription in system
- **Alert Thresholds**: Ensure threshold settings match current conditions
- **Email Client**: Some clients may block automated emails

### Performance Issues

#### **Slow Loading Times**
- **Clear Browser Cache**: Remove old cached data
- **Reduce Simultaneous Tracks**: Hide unused shark tracks
- **Check Network**: Ensure stable internet connection
- **Close Other Tabs**: Free up browser memory

#### **Mobile Performance**
- **Update Browser**: Use latest mobile browser version
- **Free Memory**: Close other mobile apps
- **WiFi Connection**: Use WiFi instead of cellular when possible
- **Reduced Motion**: Enable accessibility setting for better performance

### Data Issues

#### **Missing Shark Data**
- **Real-Time Nature**: Some sharks may not ping frequently
- **Equipment Failure**: Tags can malfunction or detach
- **Signal Interference**: Underwater conditions affect transmission
- **Maintenance Periods**: Periodic system updates may affect data

#### **Temperature Anomalies**
- **Sensor Calibration**: Equipment requires regular maintenance
- **Location Factors**: Local conditions can create unusual readings
- **Data Processing**: Real-time data may have temporary inconsistencies
- **Quality Control**: Automated systems filter most anomalies
